# Boas práticas com Git e GitHub

## 1. Utilizar mensagens claras nos commits

As mensagens dos commits devem descrever de forma clara a alteração realizada.

## 2. Organizar o trabalho utilizando branches

É importante criar branches diferentes para novas funcionalidades, correções e testes, evitando fazer todas as alterações diretamente na branch principal.

## 3. Fazer commits frequentes

É recomendado realizar commits pequenos e frequentes para facilitar o acompanhamento das alterações e a resolução de problemas.

## 4. Verificar as alterações antes do commit

Antes de realizar um commit, é importante utilizar `git status` e verificar quais arquivos foram modificados.
